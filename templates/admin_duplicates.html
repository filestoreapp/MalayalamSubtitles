🤖 How the system handles duplicates

  • On upload: No automatic duplicate prevention. If you upload the same movie twice (same IMDb ID), both entries are created independently.
  • On scheduler auto-fetch: The scheduler does check Movie.query.filter_by(imdb_id=imdb_id, media_type='movie').first() before adding — so auto-fetched movies are never duplicated.
  • On genre/search pages: Series are deduplicated by title in Python before rendering — only one poster per series shown.
  • What you should do: Review the duplicates below. Keep the entry with more translations, delete the other.
